# Learn Golang from Scratch: Build a Complete Application (Udemy)

This directory contains notes, code examples, and exercises from the Udemy course [Learn Golang from Scratch: Build a Complete Application](https://www.udemy.com/course/aprenda-golang-do-zero-desenvolva-uma-aplicacao-completa/), taught by Otavio Augusto Gallego.

The course introduces the Go programming language from its fundamentals and applies the concepts by building **DevBook**, a complete social network application. It covers practical front-end and back-end development, from the API to the web application.

## Course Summary

This course covers:

- Go fundamentals, environment setup, and writing the first program
- Language fundamentals and package organization
- Building a command-line application
- Concurrency with goroutines and channels
- Automated testing
- Additional Go language fundamentals
- Relational database integration and persistence
- Building the DevBook API
- Building the DevBook web application
- Front-end development with HTML, CSS, and JavaScript
