# Python na Prática: +150 Exercícios Resolvidos e Projetos (Udemy)

This directory contains notes, code examples, and exercises from the Udemy course Python na Prática (+150 exercícios resolvidos e projetos), a hands-on course focused on solidifying Python fundamentals through repeated practice rather than theory alone.

## Course Summary

This course covers Python fundamentals through applied exercises and small projects, including:

- Variables, data types, and conditional structures
- Loop structures (`for` and `while`)
- Python modules and built-in functions
- Basic statistics concepts applied with Python
- Writing custom functions to solve practical problems
- Object-Oriented Programming (OOP) concepts
- Working with lists, tuples, dictionaries, and sets
- List comprehensions and dict comprehensions
- Quick challenges and topic summaries for review

The course is built around practice: each section reinforces a language concept with resolved exercises and projects, ranging from beginner topics to OOP, with new exercises added on an ongoing basis.
